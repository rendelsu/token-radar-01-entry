How to read this board: every implied value is TVL times a category multiple taken from the live tokens in that category, times a seven-day growth factor and an age factor. The multiple is shrunk toward the snapshot-wide median when a category has few live comparables, so one thin comparable cannot set the price. Implied value is a model, not a price and not a promise: no row predicts that a token will launch, or when.
